# C++ 入门笔记：交互式加法程序

> 本笔记涵盖变量声明与初始化、标准输入输出、算术运算及现代 C++ 初始化语法。

---

## 1. 完整代码示例

```cpp
#include <iostream>

int main()
{
  int number1{0};
  int number2{0};
  int sum{0};

  std::cout << "Enter first integer: ";
  std::cin >> number1;

  std::cout << "Enter second integer: ";
  std::cin >> number2;

  sum = number1 + number2;
  std::cout << "sum is " << sum << "\n";
  return 0;
}
```

---

## 2. 代码逐行解析

### 2.1 头文件与入口
```cpp
#include <iostream>   // 引入输入输出流库
int main()            // 程序入口点
```

### 2.2 变量声明与初始化
```cpp
int number1{0};   // 声明 int 变量并初始化为 0
int number2{0};   // 使用列表初始化（C++11 起推荐）
int sum{0};
```

**关于 `{}` 初始化**：
- `int number1{0};` 和 `int number1 = 0;` 在功能上等价。
- 使用 `{}`（列表初始化）的优势：
  - **防止窄化转换**：`int x{3.14};` 会编译报错，而 `int x = 3.14;` 仅警告。
  - **统一语法**：适用于数组、容器、结构体等多种类型。
  - **避免"最令人头痛的解析"**：`A a();` 会被误认为函数声明，而 `A a{};` 明确为变量定义。

> **建议**：现代 C++ 编码规范（如 Google、Core Guidelines）推荐优先使用 `{}` 初始化。

### 2.3 输出提示信息
```cpp
std::cout << "Enter first integer: ";
```
- `std::cout` 是标准输出流对象（对应屏幕）。
- `<<` 是流插入运算符，将右侧字符串送入 `cout`。
- 字符串末尾不换行，方便用户在同一行输入。

### 2.4 读取用户输入
```cpp
std::cin >> number1;
```
- `std::cin` 是标准输入流对象（对应键盘）。
- `>>` 是流提取运算符，从 `cin` 读取数据存入变量。
- 程序会在此处阻塞，等待用户输入并回车。

### 2.5 计算与输出结果
```cpp
sum = number1 + number2;
std::cout << "sum is " << sum << "\n";
```
- `sum = number1 + number2;` 执行加法并赋值。
- 输出语句使用 `<<` 拼接多个内容：字符串字面量、变量、换行符。
- `"\n"` 是换行符（与 `std::endl` 功能类似，但不刷新缓冲区，性能更好）。

## 3. 核心知识点总结

### 3.1 变量三要素
| 要素 | 示例 | 说明 |
|------|------|------|
| **类型** | `int` | 决定占用的内存大小和存储格式 |
| **名称** | `number1` | 标识符，用于引用变量 |
| **初始值** | `{0}` | 建议声明时初始化，避免随机值 |

### 3.2 输入输出的方向（消除困惑）
| 操作 | 语句 | 数据流向 |
|------|------|----------|
| **输出** | `std::cout << "文本";` | 数据 `"文本"` → `cout` → 屏幕 |
| **输入** | `std::cin >> number1;` | 键盘 → `cin` → `number1` |

**记忆口诀**：
- `<<` 箭头指向哪里，数据就流向哪里（指向 `cout` 表示输出，指向变量表示输入？）
- **更准确的理解**：
  - `cout << x`：把 `x` 送入 `cout`（输出到屏幕）。
  - `cin >> x`：从 `cin` 取出数据存入 `x`（从键盘读入）。

### 3.3 `\n` vs `std::endl`
| 写法 | 效果 | 适用场景 |
|------|------|----------|
| `"\n"` | 仅换行 | 大多数普通输出，性能更好 |
| `std::endl` | 换行 + 刷新缓冲区 | 需要立即显示输出时（如交互程序、日志） |

> 本示例中使用 `"\n"` 是更高效的选择。
