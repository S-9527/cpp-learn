# C++ 入门笔记：第一个程序与基础语法

> 涵盖 C++ 程序结构、注释、输入输出及 `main` 函数返回值等核心概念。

---

## 1. 完整代码示例

```cpp
#include <iostream>

int main()
{
  std::cout << "welcome to c++" << std::endl;
  return 0;
}
```

---

## 2. 代码逐行解析

### 2.1 头文件包含 `#include <iostream>`
- `iostream` 是 C++ 标准库中的**输入输出流**头文件。
- 它提供了 `std::cin`（输入）、`std::cout`（输出）等功能。
- 类似于 C 语言的 `#include <stdio.h>`，但采用面向对象的流方式。

### 2.2 主函数 `int main()`
- 每个 C++ 程序**有且仅有一个** `main` 函数，它是程序的入口点。
- 返回类型为 `int`（整数），用于向操作系统返回执行状态。
- 圆括号 `()` 表示无参数，也可以写 `void`，但通常省略。

### 2.3 输出语句 `std::cout << "...";`
- `std::cout` 是标准输出流对象（对应屏幕）。
- `<<` 是**流插入运算符**，将右侧的内容送入 `cout`。
- `std::endl` 表示换行并刷新输出缓冲区（相当于 `\n` + 刷新）。
- 字符串字面量用双引号括起。

### 2.4 `return 0;`
- `main` 函数返回 `0` 表示程序**正常结束**。
- 虽然 C++ 标准允许 `main` 不写 `return`（编译器会隐式加 `return 0;`），但显式写出是**良好编程习惯**，能清晰表达意图。
- 非零返回值通常表示错误或异常状态。

## 3. 注释的使用

C++ 支持两种注释格式：

| 类型 | 格式 | 说明 |
|------|------|------|
| **单行注释** | `// 注释内容` | 从 `//` 开始到行尾结束，常用于简短说明。 |
| **多行注释** | `/* 注释内容 */` | 可跨多行，但**不能嵌套**（即不能 `/* /* */ */`）。 |

> **注意**：虽然写 `/** */` 在 C++ 中语法合法，但 C++ **没有原生文档注释**。若想生成文档，需借助 Doxygen 等第三方工具。

---

## 4. 关于 `main` 函数的“隐式返回”

- C++ 标准规定：如果 `main` 函数执行到末尾没有遇到 `return`，编译器会**自动插入 `return 0;`**。
- 所以以下写法也是合法的：
  ```cpp
  int main()
  {
      std::cout << "Hello\n";
  }   // 等同于 return 0;
  ```
- **但强烈建议显式写 `return 0;`**，原因：
  - 代码意图更明确。
  - 避免依赖编译器特性，增强可移植性。
  - 便于代码审查和静态分析工具检查。

## 5. 常见问题与扩展

### Q：`std::endl` 和 `\n` 有什么区别？
- `\n` 仅换行。
- `std::endl` 换行 + **刷新输出缓冲区**，适用于需要立即显示输出的场景（如交互程序）。频繁使用会影响性能。

### Q：`std::cout` 中的 `std` 是什么？
- `std` 是 C++ 标准库的**命名空间**。
- `cout`、`endl` 等都定义在 `std` 中，通过 `std::` 前缀访问。
- 也可以使用 `using namespace std;` 省去前缀，但一般不推荐（易引起命名冲突）。

### Q：如果返回非零值会怎样？
- 操作系统或调用进程可以捕获该值，用于判断程序是否执行成功。例如 Shell 脚本中可通过 `$?` 获取上一个程序的返回值。
