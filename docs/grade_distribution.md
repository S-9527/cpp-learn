# C++ 入门笔记：频率直方图与 `std::array`

> 本笔记通过绘制学生成绩分布的直方图，演示 `std::array`、类模板参数推导（CTAD）、`constexpr` 数组、C++20 范围 `for` 循环初始化式以及 `std::format` 的格式化输出。

---

## 1. 完整代码示例

```cpp
#include <array>
#include <format>
#include <iostream>

int main() {
  constexpr std::array frequencies{0, 0, 0, 0, 0, 0, 1, 2, 4, 2, 1};

  for (int i{0}; const int& frequency : frequencies) {
    if (i < 10) {
      std::cout << std::format("{:02d}-{:02d}: ", i * 10, (i * 10) + 9);
    } else {
      std::cout << std::format("{:>5d}: ", 100);
    }

    ++i;

    for (int stars{0}; stars < frequency; ++stars) {
      std::cout << "*";
    }

    std::cout << "\n";
  }

  return 0;
}
```

---

## 2. 代码逐行解析

### 2.1 头文件与 CTAD
```cpp
#include <array>    // std::array 容器
#include <format>   // C++20 格式化输出
#include <iostream> // 标准输入输出

constexpr std::array frequencies{0, 0, 0, 0, 0, 0, 1, 2, 4, 2, 1};
```
- 使用**类模板参数推导（CTAD，C++17）**，编译器自动推导出 `std::array<int, 11>`。
- `constexpr` 表示该数组是**编译期常量**，内容在编译时确定。
- 数组包含 11 个元素，索引 0~10 分别对应分数段 0-9、10-19、……、90-99，以及 100 分。
- 频率值表示每个分数段的学生人数。

### 2.2 外部循环：遍历频率数组
```cpp
for (int i{0}; const int& frequency : frequencies) {
    // ...
    ++i;
}
```
- 这是 **C++20 的范围 `for` 循环带初始化式**（init-statement）。
- `int i{0}` 在循环开始前初始化，作用域覆盖整个循环（包括 `for` 的声明部分和循环体）。
- 循环变量 `frequency` 是 `frequencies` 中每个元素的**常量引用**（只读）。
- 每次迭代后，手动执行 `++i` 来更新分段编号（用于输出标签）。

### 2.3 输出分段标签
```cpp
if (i < 10) {
    std::cout << std::format("{:02d}-{:02d}: ", i * 10, (i * 10) + 9);
} else {
    std::cout << std::format("{:>5d}: ", 100);
}
```
- `i` 从 0 到 10：
  - 当 `i < 10` 时，输出 `"00-09: "`, `"10-19: "`, ... , `"90-99: "`。
  - 当 `i == 10` 时，输出 `"  100: "`（右对齐，宽度 5）。
- `{:02d}` 表示整数以两位数字输出，不足补零（如 `00`、`09`）。
- `{:>5d}` 表示整数右对齐，占 5 个字符宽度（此处输出 `  100`）。

### 2.4 内部循环：打印星号
```cpp
for (int stars{0}; stars < frequency; ++stars) {
    std::cout << "*";
}
```
- `frequency` 是该分数段的人数。
- 循环 `stars` 从 0 到 `frequency - 1`，每循环一次打印一个星号。
- 若 `frequency` 为 0，则不打印任何星号。

### 2.5 换行
```cpp
std::cout << "\n";
```
- 每个分数段输出完毕后换行。

## 3. 核心知识点

### 3.1 CTAD（类模板参数推导）
- C++17 起，编译器可从初始化列表推导类模板参数。
- 示例：`std::array frequencies{...}` → `std::array<int, 11>`。
- 注意：元素类型必须一致，否则推导失败。

### 3.2 `constexpr` 数组
- `constexpr` 变量在**编译期**求值，可作为模板参数（如数组大小）。
- 本例中 `frequencies` 是编译期常量，存储固定的频率数据。
- 若需要从文件或用户输入读取频率，则不能使用 `constexpr`。

### 3.3 范围 `for` 循环的初始化式（C++20）
- 语法：`for (init; declaration : range)`。
- `init` 可以声明一个或多个变量（用逗号分隔），作用域覆盖整个循环。
- 本例中 `int i{0}` 在循环内使用，无需在外部单独声明。
- 比传统 `for` 循环更简洁，尤其当需要维护循环索引时。

### 3.4 `std::format` 格式化输出（C++20）
- 类型安全、性能良好的格式化库。
- 格式说明符：
  - `{:02d}`：整数，宽度为 2，不足补零。
  - `{:>5d}`：整数，右对齐，宽度为 5。
- 支持多种类型（整数、浮点、字符串等）。

### 3.5 嵌套循环与直方图绘制
- 外层循环遍历频率数组，内层循环根据频率值打印星号，形成条形图。
- 这是数据可视化的一个简单示例，常用于统计报告。

## 5. 改进建议

### 5.1 使用 `std::string` 构造星号行
```cpp
std::string stars(frequency, '*');
std::cout << stars << '\n';
```
- 更简洁，但需要包含 `<string>`。

### 5.2 根据最大频率动态调整图例
- 可先找出最大频率值，然后按比例缩放星号，避免过长条形。

### 5.3 使用 `std::views::enumerate`（C++20 库）
```cpp
#include <ranges>
for (const auto& [i, frequency] : std::views::enumerate(frequencies)) {
    // i 自动从 0 开始递增
}
```
- 消除了手动 `++i`，但需 C++20 及 `<ranges>` 支持。

### 5.4 增加表头说明
```cpp
std::cout << "Grade Distribution:\n";
```

### 5.5 支持从输入读取频率数组
- 将 `frequencies` 改为 `std::array<int, 11> freq{};` 并通过 `std::cin` 填充。

## 7. 注意事项

- 范围 `for` 循环的初始化式（`int i{0}`）是 C++20 特性，若编译器不支持，可在循环外部声明 `i`。
- `std::format` 是 C++20 特性，若编译器不支持，可改用 `std::cout` 流式输出。
- 数组索引 `i` 在循环体内被修改（`++i`），但循环变量 `frequency` 不受影响（它只是对当前元素的引用）。
